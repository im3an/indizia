Everything in the web version, running on your own computer, plus tools a browser cannot run. Free, no account, and nothing leaves your machine unless a source has to be asked.

    What the desktop app adds

    Local toolbox

    Runs ProjectDiscovery subfinder (passive subdomain discovery from about 50 sources), dnsx (which names still resolve) and, if you switch it on, httpx (live web servers and technologies) on domain searches. Results land in the ledger, graph and evidence drawer like every other source.

    Clean, throwaway containers

    Each tool runs in Docker as an unprivileged user, read-only, without Linux capabilities, with memory and process limits, and is removed when it finishes. Images are pinned to exact versions. One click removes them again.

    Isolated network engine

    Optionally, every server-side request (relay, username checks, website fingerprint, icons) is made from a locked-down container instead of the app, and the container is removed when you quit.

    No open port

    The app serves itself over a private in-app protocol inside its own window. No local web server is listening, so other programs and websites cannot reach it.

    Your own limits

    No shared deployment means ten times the request allowance for the relay, username checks and fingerprint. Requests come from your connection, as if you visited the source.

    Native feel

    App menu with keyboard shortcuts, ⌥⇧S from anywhere to bring up the search box, native save dialogs for every export, and links that open in your normal browser.

    Requirements

    • macOS 12 or newer, Windows 10 or 11 (64-bit), or a 64-bit Linux desktop.
    • Docker is optional. Without it the app works exactly like the web version. With Docker Desktop, OrbStack or Docker Engine running, the toolbox and the isolated engine become available. subfinder and dnsx are about 45 MB to download; httpx about 275 MB.

    First launch

    Indizia is free and has no budget for paid code-signing certificates, so your system will warn you once. Each build is made in public by GitHub Actions from the source code, and you can check that the file you downloaded is that build (see below).

    • macOS: open the app once. When macOS says it cannot verify the developer, click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway next to Indizia, then confirm. You only do this once.
    • Windows: if SmartScreen shows Windows protected your PC, click More info → Run anyway.
    • Linux: make the AppImage executable (chmod +x Indizia-linux-x86_64.AppImage) and run it.

    Check your download

    Every release lists SHA-256 checksums in SHA256SUMS.txt and carries a build attestation signed by GitHub. With the GitHub CLI:

    gh attestation verify Indizia-mac-arm64.dmg --repo im3an/indizia

    Build it yourself

    Needs Node 20 or newer. The installer ends up in desktop/dist/.

    git clone https://github.com/im3an/indizia.git
cd indizia
npm install
cd desktop
npm install
npm run dist

    To try it without packaging, run npm start in desktop/ instead.

    Prefer a server?

    Run Indizia in a hardened container and open it in your browser (the toolbox stays desktop-only, because a server container should not control Docker):

    docker compose up -d

    Then open http://127.0.0.1:8080. Details in the README.
